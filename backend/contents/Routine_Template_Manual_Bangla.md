# ক্লাস রুটিন টেমপ্লেট পূরণ করার নিয়ম 

এই এক্সেল ফাইলটি দিয়ে আপনি নিজের বিভাগের ক্লাস রুটিন তৈরি করার জন্য প্রয়োজনীয় তথ্যগুলো সাজিয়ে দেবেন। ফাইলটি সঠিকভাবে পূরণ করলে সিস্টেম নিজে থেকেই একটি রুটিন তৈরি করে দেবে। 

ফাইলটির নিচে অনেকগুলো "শীট" (Sheet/ট্যাব) আছে — Excel-এর একদম নিচে ট্যাব হিসেবে দেখা যায়। প্রতিটি শীটে আলাদা আলাদা তথ্য রাখতে হয়। নিচে ধাপে ধাপে বলা হলো কোন শীটে কী লিখবেন। 

## শুরু করার আগে কয়েকটি জরুরি নিয়ম

- **কোনো শীটের নাম পরিবর্তন করবেন না** এবং **হেডার সারি (প্রথম সারি) মুছবেন না**।
- হেডারে যে কলামের নামের পাশে **`*` (তারকা চিহ্ন)** আছে, সেটা **অবশ্যই পূরণ করতে হবে**।
- অনেক কলামে **ড্রপডাউন (dropdown)** আছে — ঐ ঘরে ক্লিক করলে একটা তালিকা থেকে অপশন বেছে নিতে হয়, নিজে হাতে লেখা যায় না। 
- প্রতিটা শীটের শেষ কলামে একটা **status** কলাম আছে, যেটা এমনিতেই automatic হিসাব হয়ে যায় — এখানে কিছু লিখবেন না।
- সব শেষে ফাইলটি `.xlsx` ফরম্যাটেই সেভ করবেন।

---

## শীট পূরণ করার সঠিক ক্রম

**Lists → Config (আগে Faculty, তারপর Department, তারপর Year, তারপর Semester) → Year_Sem → Teachers → Credit_Rules → Courses → Rooms → Room_Preference → Day_Preference → Teacher_Unavailability**

এই ক্রম মেনে চললে ড্রপডাউনগুলোতে সঠিক অপশন পাবেন, কারণ পরের শীটের ড্রপডাউন আগের শীটের তথ্যের উপর নির্ভর করে।

---

## status ও রঙের মানে (খুব গুরুত্বপূর্ণ)

- **হলুদ রঙের ঘর** = কোনো **আবশ্যিক (`*` চিহ্নিত)** তথ্য এখনো দেওয়া হয়নি।
- **লাল "status"** (যেমন DUPLICATE, INVALID, OVERLAPPING) = ডেটাতে ভুল আছে — ঠিক করে দিতে হবে।
- **"OK"** = ঐ সারির তথ্য ঠিক আছে।

সব শীট পূরণ করার পর **Summary** শীটে গিয়ে একবার চেক করে নিন — সব ঠিক থাকলে সব জায়গায় "OK" দেখাবে।

---

## ০. Summary শীট — সবকিছু ঠিক আছে কিনা এক নজরে দেখার জায়গা

এখানে নিজে কিছু লিখতে হবে না। এখানে দেখানো হয় মোট কতজন শিক্ষক/কোর্স/রুম যোগ করা হয়েছে, কোনো কোর্সে শিক্ষক বাকি আছে কিনা, এবং কোথাও কোনো conflict আছে কিনা। সব শীট পূরণ করার পর সবার শেষে এখানে এসে দেখে নিন সব জায়গায় **"OK"** আছে কিনা। নিচে **Quick Links** থেকে সরাসরি অন্য শীটে যেতে পারবেন।

## ১. Lists শীট — ড্রপডাউনের তালিকা (সবার আগে দেখুন)

দরকারি কোনো অপশন অন্য কোনো শীটের ড্রপডাউনে না পেলে এখানে এসে সংশ্লিষ্ট কলামের নিচে নতুন সারিতে যোগ করে দিন।

| কলাম            | কীসের তালিকা                                                    |
| --------------- | --------------------------------------------------------------- |
| Config_Year     | Config শীটে বাছাই করার জন্য শিক্ষাবর্ষের তালিকা                 |
| Config_Semester | Fall / Spring                                                   |
| Faculty         | অনুষদের তালিকা                                                  |
| Department     | বিভাগের নাম (যেমন CSE, EEE, ETE, ACCE, CE, ARCH ইত্যাদি)        |
| Designation     | শিক্ষকদের পদবি                                                  |
| Time            | সময়ের তালিকা                                                   |
| Year            | বর্ষ (১-৪)                                                      |
| Semester        | সেমিস্টার (১-২)                                                 |
| year_sem        | বর্ষ-সেমিস্টার কোড                                              |
| Year_Group      | বর্ষ-সেমিস্টার গ্রুপ (1-2, 3-4)                                 |
| Credit_Type     | Theory / Lab                                                    |
| Room_Type       | classroom / lab                                                 |
| Day             | সপ্তাহের দিন                                                    |
| Yes_No          | Yes / No                                                        |

ডানদিকে **dep_...** নামের কলামগুলো (dep_Engineering_Faculty ইত্যাদি) প্রতিটা অনুষদের অধীনে কোন কোন বিভাগ আছে তার তালিকা রাখে। Config শীটে Faculty বাছাই করলে Department ড্রপডাউনে শুধু সেই অনুষদের বিভাগগুলো দেখাবে। নতুন বিভাগ যোগ করতে চাইলে সংশ্লিষ্ট অনুষদের dep_ কলামে নাম দিয়ে যোগ করুন।
